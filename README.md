## 🚀 Featured Projects

### 🔬 ResearchLab — Multi-Agent AI Research System

An AI-powered research workflow that coordinates specialized agents to turn a research topic into a structured report.

- **Search Agent:** Finds relevant web sources using Tavily.
- **Reader Agent:** Extracts webpage content using BeautifulSoup.
- **Writer Agent:** Generates research reports using the Gemini API.
- **Critic Agent:** Reviews drafts for clarity and supporting evidence.

**Tech Stack:** Python · LangChain · FastAPI · Tavily · BeautifulSoup · Google Gemini API

### 🩺 AI Healthcare Disease Prediction

A machine learning application that predicts potential diseases from user-reported symptoms.

- Supports 41 disease classes and 132 symptoms.
- Uses a Bernoulli Naive Bayes classifier.
- Includes a Flask application and SQLite database.

**Tech Stack:** Python · Scikit-learn · Flask · SQLite

### 🏡 LIV.AI — AI-Powered Interior Design

An AI-based interior design application exploring room analysis, depth estimation, color understanding, and furniture recommendations.

**Tech Stack:** React · FastAPI · Python · Computer Vision

### 🌾 FarmFresh AI — Smart Agriculture Platform

A smart agriculture platform concept designed to connect farmers directly with consumers and explore AI-driven agricultural insights.

**Tech Stack:** React · Python · Machine Learning
